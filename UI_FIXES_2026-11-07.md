# Waselni UI fixes — 7 November 2026

## Implemented

- Reworked the customer store-order product selector into responsive product cards with a separate image area, product name, price, description, and visible selection state.
- Added explicit merchant/product loading, empty, and error states. Product requests are refreshed when a store is selected and stale responses are ignored.
- Kept the existing product/order API contract and backend-side price and inventory validation. No database schema or migration changes were made.
- Added a global fixed toast viewport at the app root, above sticky navigation, maps, cards, and clipped containers. API success/error feedback used by key order, catalog, settlement, support, and captain actions now appears there.
- Forced merchant catalog product cards to keep image and text in separate layout regions so the product description cannot be covered by the image.
- Added mobile-specific layout rules for the product selector, catalog cards, and toast viewport.

## Important source limitation

The ZIP supplied for this update does not contain a notification center/device-token page or notification/device-token backend models/endpoints. The toast layer implemented here displays in-app action feedback; it does not create persistent notifications or send Firebase push notifications. The notification center/device-token workflow must be integrated from the correct newer source tree if it exists.
