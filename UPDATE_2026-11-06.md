# Waselni update — 2026-11-06

## Applied in this source update

### API connectivity and authentication
- Changed the frontend API default from the browser-local `127.0.0.1:8000` URL to same-origin `/api`.
- Added Vite proxy routes for `/api`, `/media`, and `/ws`, targeting Django at `127.0.0.1:8000` by default. This avoids the common `Failed to fetch` problem when the browser is opened from another device on the same LAN.
- Added an optional `WASELNI_BACKEND_URL` proxy override.
- Added access-token refresh and one retry after an expired access token.
- Improved network and validation error messages so the UI shows the API target or useful server validation details.
- Sign-out now removes only authentication tokens and preserves the selected language preference.

### Visual refresh
- Refined the lavender/purple palette, page surfaces, spacing, typography, forms, cards, tables and responsive layout.
- Replaced the mixed text-symbol navigation with a consistent set of inline SVG icons (no icon CDN or extra runtime dependency).
- Improved login/registration card layout and ride booking location cards/map framing.
- Added clearer focus styles and reduced-motion handling.

### Existing features retained
- Customer, merchant, captain and admin roles.
- Profile image upload/update/removal with a fallback avatar.
- Merchant catalog, orders, reporting and cash settlements.
- Captain onboarding document uploads, approval/eligibility and dispatch controls.
- Customer scooter ride booking with map coordinates and checkpoint fee selection.
- Arabic, Hebrew and English interface direction/language support.

## Local startup (Windows)

Backend terminal:

```bat
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 127.0.0.1:8000
```

Frontend terminal:

```bat
cd frontend
copy .env.example .env
npm install
npm run dev
```

Open `http://localhost:5173`. Keep the Django terminal running while using the app.

If Django runs on another address/port, set `WASELNI_BACKEND_URL` in the environment before starting Vite, for example `http://127.0.0.1:8001`.

## Verification and limitations
- Python source compilation passed (`python -m compileall`).
- CSS brace balance passed.
- Vite production build could not be executed in this environment because `frontend/node_modules` is not installed. Run `npm install` then `npm run build` on the development machine.
- Django runtime checks and API integration tests could not be executed here because Django dependencies are not installed in this environment.
- External services still need their own credentials/configuration before production use: real road routing and automatic checkpoint detection, SMS/OTP, push notifications, VoIP, payment gateway, and production-grade live GPS.
- The ride price remains the configured straight-line estimate plus the manually selected checkpoint fee; it is not a road-route quote.

## Important existing account behavior
- Self-registration is enabled for customer, merchant and captain roles; admin accounts cannot be created through public registration.
- Merchant stores start closed pending admin activation; captain accounts start pending administrator approval.
- Merchant/captain operational actions remain gated by the subscription and approval rules already implemented in the backend.
- Updated the PWA service worker cache version and made navigation network-first; API, media and WebSocket requests are explicitly excluded from service-worker caching to avoid stale app shells or cached operational data.
- Updated the browser theme color to match the Waselni violet identity.
